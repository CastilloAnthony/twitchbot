WolfBot API Access

Paths

  • /bot/status
    • - Returns boolean value.
    • - True/False
  • /bot/channels
    • - Returns a list of channels the bot is currently connected to.
    • - List[str,]
  • /bot/commands
    • - Returns a list of commands.
    • - TBD
  • /bot/settings
    • - Returns a dictionary of values that the bot is set to.
    • - Dict{key: value}
  • /bot/bannedUsers
    • - Returns a list of users that have been bannedUsers.
    • - List[str,]
